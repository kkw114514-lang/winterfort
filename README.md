# Winterfort

Winterfort 是一款处于前期开发阶段的 PvE 卡牌肉鸽游戏。核心体验以牌组构筑、敌人意图和双属性路线为主，使用 Godot 4.7.1 与 C#/.NET 8 开发。

> 当前仓库是开发快照，不是可发布版本。设计文档、代码和世界观正在同步，部分内容仍是待裁提案。

## 当前玩法方向

- 契约师是唯一行动主体，也是敌人唯一可攻击的目标。
- 精灵提供一个常驻被动和一张专属卡，不存在主动技能、战斗按钮或冷却。
- 五种属性为火、水、草、光、暗，只表示玩法类型，不存在属性克制。
- 当前基础标尺为 80 最大生命、每回合抽 5 张牌、每回合 3 点能量。
- 当前首个可玩切片为“王女 × 炎舞”：11 张初始牌组、赤金王印、通用基石、火系卡池和第一层敌人。

## 运行方式

已验证环境：

- .NET SDK 8.0.424（其他受支持的 .NET 8 SDK 也可尝试）
- Godot 4.7.1 stable .NET 版（不要使用 Standard 版）

编译完整解决方案：

```bash
dotnet build rouge-2.0/rouge-2.0.sln --configuration Debug
```

运行无头检查：

```bash
dotnet run --project src/Kernel.Headless/Kernel.Headless.csproj
```

打开 Godot 客户端：

```text
rouge-2.0/project.godot
```

上传到 GitHub 后，`.github/workflows/verify.yml` 会在每次推送和拉取请求时自动编译 C# 战斗内核并运行同一套无头检查。Godot 客户端继续通过本地编辑器做场景与资源验证。

## 设计资料的使用顺序

1. 先读 `design/00_项目规范_当前版/00_现行文件索引.md`。
2. 具体规则以对应当前版表格中的“规则／机制词典／评审执行”工作表为准。
3. 世界观只把明确标为“已定”的内容视为正史；“提案”“二层提案”“待裁”均不自动升格。
4. `legacy/` 中的内容已被当前 C# 架构和现行设计取代，不可反向覆盖当前规则。
