# 旧版 GDScript 原型

这是 `rouge-1.0` 的历史快照，用于保留早期战斗逻辑、1080p 战斗 UI、组件、皮肤和冒烟测试。

当前主线已经迁移到仓库根目录的 C# 内核和 `rouge-2.0/` Godot 工程。本目录：

- 不再作为当前规则来源；
- 不应直接与新版代码混合编译；
- 适合作为 UI 布局、素材槽、交互与旧实现的迁移参考。

为便于上传，本快照移除了 `.godot/` 缓存、资源 `.import` 文件、本地 `.vscode` 配置、旧 `AGENTS.md` 和第三方 Godot MCP 插件。完整 39 次提交的原始仓库仍保存在离线备份中。
