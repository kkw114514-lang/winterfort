## 一、词库（同义只留一个）

| 类别 | 标准写法 | 废语 |
|---|---|---|
| 伤害 | `造成X点伤害` | 威力 |
| 群体伤害 | `对敌方全体造成X点伤害` | |
| **随机单体** | `对随机1个敌人造成X点伤害`／`对随机1个敌人施加N层灼伤I` | 随机敌方、任意一个敌人 |

## 二、句法

- **费用修正句永远第一句**：`当前连击数每有3，这张卡费用-1（最低为0）。`（废「本卡」「（最低0）」）
- **机制关键词短形后置**（主效果 → `焚毁2。`/`余烬1。`→ `消耗。`）；**`消耗。` 永远最后一句**；`燃料：被消耗时，X。` 独立成句。
- 独立效果用句号分隔；代价—收益对可逗号连写（F44）。
- 条件：`若A，B` / `若A，改为B`；触发：`每当A时，B`、`本回合每打出1张牌，B`。
- 时限：`本回合` / **`本场战斗中`**（废「本场」单用、「本局对战中」）；持续触发：`本场战斗中，每回合开始/结束时，…`。
- **可累积效果**：主句写清单次效果，累积性另起一句 `本场战斗中可重复叠加。`（F79 范式）。
- 「你」可用（`本场战斗中你的连击数…`）；**无主语默认 = 契约师**。

## 三、单位与计数

- 力量、护盾、能量、伤害按「点」；灼伤/虚弱 =「层」+「等级」（罗马 I–Ⅳ，上限Ⅳ）；**连击按「数」计（连击数），不用"层"**。
- 读当前值冠 `当前`；变量式：`重复N次（N=当前连击数）`、`获得N点力量（N=…）`。
- 数字与运算符半角，标点全角。

## 四、词典依据（既有定义，卡面不再解释）

- **被动触发的默认目标（裁定10·通用规则）** = 效果在被动触发时（燃料被消耗、状态到期等）若无指定目标，**对随机 1 个敌人生效**。卡面在有变数、影响决策时仍应写明 `对随机1个敌人`，不省略。
- **增益归属** = 恒为契约师（唯一行动主体），卡面不写归属。
- **焚毁X** = 打出此卡时额外从手牌烧掉**你选择的** X 张（进消耗堆）→ 关键词后置纯排版、不改结算。
- **灼伤** = 层数归零整条消失（等级不能脱离层数存在）；施加时等级累加封顶Ⅳ、层数取较大值。
- **余烬** = 生成的状态牌（1费打出、无效果、消耗）；打出的余烬与被焚毁的牌都计入消耗堆。
