# 世界观资料说明

本目录同时包含“已定事实”和“作者提案”，阅读时必须保留状态区别。

## 使用顺序

1. `00_剧情设计准则_v2_2026-08-08.md`：读取世界观已定清单、已否清单和待裁清单。
2. `00_版本说明.md`：确认当前目录内各文件的用途和状态。
3. 组织、王室和五系群像文档：均按文件内部的【已定】【提案】【二层提案】【待裁】标记使用。
4. 美术定调与出图 Prompt：只负责视觉方向，不反向决定卡牌和战斗机制。

## 已知版本冲突

《剧情设计准则 v2》的跨部门章节仍沿用旧的“精灵主动技”口径。当前机械规则已经更新为：

- 精灵只提供一个被动特性和一张专属卡；
- 不存在主动技能、战斗按钮、充能或冷却；
- 当前规则以 `design/00_项目规范_当前版/00_现行文件索引.md` 为准。

世界观已定事实仍可从该准则读取，但不能用其中的旧机械口径覆盖当前设计。
