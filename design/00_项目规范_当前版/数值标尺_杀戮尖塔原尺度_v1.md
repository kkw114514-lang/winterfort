# 数值标尺｜杀戮尖塔原尺度 v1

> 状态：现行真理文档。任何新卡、精灵专属卡、遗物和敌人数值先按本表定价，再由实战数据修正。

## 一、固定基准

| 项目 | 现行值 |
|---|---:|
| 契约师最大生命 | 80 |
| 每回合抽牌 | 5 |
| 每回合能量 | 3 |
| 打击 | 1费，6伤害 |
| 守护 | 1费，5护盾 |
| 破防 | 2费，8伤害，2层易伤 |
| 力量 | 每点使每次命中伤害+1 |

## 二、卡牌粗标尺

| 费用与形态 | 常见安全区 | 说明 |
|---|---:|---|
| 0费纯伤害 | 3–6 | 需要消耗、条件或真实代价；否则容易成为循环零件 |
| 1费纯伤害 | 6–10 | 10以上通常要条件、延迟或负面代价 |
| 2费纯伤害 | 13–20 | 20以上应有高段位、明显条件或自损 |
| 3费纯伤害 | 24–32 | 32可作极端基准，不应普遍出现 |
| 1费纯护盾 | 5–9 | 附带抽牌、生长等价值时向下取 |
| 2费纯护盾 | 12–20 | 超过20必须有条件或消耗 |
| 抽牌 | 1能量≈2张 | 0费抽牌必须带限制、消耗或真实代价 |
| 能量 | +1已很强 | 无条件每回合+1禁止；爆发能量要消耗或付生命 |

数值区间不是公式。多段会放大力量，抽牌与能量会放大整副牌，消耗会提高短战一致性；这些必须单独加价。

## 三、状态与特殊数值

- 中毒：回合结算造成等于当前层数的伤害，随后减少1层。
- 荆棘：受到攻击伤害时，对攻击者造成等于当前层数的伤害；多段攻击逐段触发。
- 生长：卡牌每次打出并完成结算后，永久强化卡面指定项目；费用最低为0。
- 猎获：必须由该牌的伤害完成击杀才发放奖励；召唤物默认不触发金币、道具与额外卡牌奖励。
- 虚弱：固定使攻击伤害降低25%，只记录持续回合；重复施加只延长持续时间。
- 9999债务：保留9999点普通伤害，不缩放、不设系统上限；允许护盾、免疫、替身或死亡规避制造“作弊成功”的爽点。

## 四、不参与缩放的量

费用、能量、抽牌张数、弃牌张数、层数、重复次数、百分比、金币、商店价格、地图次数、卡牌数量和9999债务都不是战斗点数，不做除以10处理。

## 五、敌人与遗物

- 一层普通怪约9–74生命；小击4–8，主力单击11–14，敌方护盾5–10。
- 常见开战护盾可用10作基准；空盾回合末护盾用6；指定回合护盾约12–14。
- 战后回复3是普通旅途遗物基准；角色信物可到6。
- 直接伤害遗物低频3–6，条件爆发5–12，并限制群体与循环触发。

## 六、自查清单

1. 是否仍出现800生命、60打击、50守护或“×10换算”？
2. 是否把费用、抽牌、能量、层数或金币也错误除以10？
3. 是否存在抽牌—能量—耗尽的无上限闭环？
4. 多段伤害、群怪与复制是否把触发次数放大三倍以上？
5. 同一属性是否有两张只换名字的同构卡？
6. 角色信物是否足够泛用，而不是强绑某只精灵？
7. 卡面是否只写结算事实，把公式、历史版本和设计理由留在备注列？
