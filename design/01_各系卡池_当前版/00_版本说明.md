# 各系卡池当前版本

本目录只保留当前可供设计、评审与程序实现读取的卡池。

| 内容 | 当前版本 |
|---|---|
| 通用基石 | V3 StS原尺度 |
| 火系 | V8 涉水同步版 |
| 暗系 | V9 涉水同步版 |
| 草系 | V9 涉水同步版 |
| 水系 | V8 升级审阅定稿版 |
| 光系 | V12 最新设计稿 |
| 双系胶水卡 | V8 水系升级同步版 |
| 无色卡池 | V1 评审定稿版 |

虚弱统一为固定25%攻击减伤，只累计持续回合。纯抽牌按1费抽3，纯护盾按1费8点、2费14点。水系牌序条件全部使用自然语言，不再使用“顺流”关键词。光羽是光系0费衍生伤害牌。草系敏捷只提高卡牌直接获得的护盾，不提高树皮等状态产生的护盾。无色牌没有属性标签，主要来自商店、事件、遗物与光系生成牌。

光系V12以最新设计稿为准，共39张实体牌与2张衍生牌；L037辉盾已删除。该版重新定义光羽、神启、神临与起飞。神临改为“下一张牌额外打出1次”；起飞的层数递减方式与随机生成的取牌池仍待设计师裁定。水系V8完成全部基础牌与升级效果审阅，共66张，其中31张纯水、35张双系；W028、W046与旧L024删除。双系胶水卡V8共81张，其中35张涉水牌已同步升级字段；涉水光系牌统一使用神启与法术牌用语。其他属性双系牌的升级字段将在对应属性升级阶段回填。

延迟到下回合结算的牌直接使用自然语言描述，不使用“蓄力”关键词。

`评审文稿` 子目录只存放尚未通过设计师审议的候选稿。程序不得读取其中的编号或卡面；审议通过后再合并进对应执行表。已经合并或被新裁定覆盖的旧文稿直接删除。
